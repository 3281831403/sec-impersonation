客服工具支持代替用户操作，可日志里看起来全是用户自己做的，事后完全追不到人：代登录会话必须同时记录真实操作者与被代用户，代登录有时限且不可续期，不得代登录管理员账号，代登录期间的高危操作必须二次确认，退出代登录必须立即恢复，批量处理各会话独立。不变量是任何代登录期间的操作都能定位到真实操作者，代登录会话结束后原状态完全恢复。

## 运行

在仓库根目录执行：

    python -m pytest tests -q
